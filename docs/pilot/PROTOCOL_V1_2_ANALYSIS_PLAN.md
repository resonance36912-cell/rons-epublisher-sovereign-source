# Production Protocol v1.2 Candidate — Analysis Plan v1.2-a1

Scope: six-page illustrated-biography controlled pilot.

## Primary operational outcome

Approved-book acceptance rate = books approved under the frozen rubric / all started benchmark jobs. Failed, interrupted, and repaired jobs remain in the denominator.

## Secondary outcomes

- First-pass acceptance before correction.
- Valid required exports / jobs requiring those exports.
- Unsupported claims per book and per reviewed factual claim.
- Required-fact coverage.
- Provider spend per approved book, including failures and repairs.
- Human review/correction minutes per approved book.
- Blind preference among completed outputs, reported separately from acceptance.
## Repeated runs and uncertainty

Repeated runs within a brief and multiple ratings of the same book are not treated as independent observations. Confirmation analysis must account for clustering/repeated measures. Unseen confirmation briefs are reserved until after tuning.

A competitive superiority statement is permitted only if the prespecified analysis passes and the uncertainty interval for the primary improvement lies entirely above the frozen minimum-meaningful-improvement threshold.

## Parameters that must be frozen before benchmark execution

The freeze record must name the comparator product and plan, correction allowance, spending ceiling, minimum meaningful improvement, statistical method, stopping rule, tie/failure/unsupported-input treatment, and named approval authority. These values are intentionally not invented by the implementation.

## Failure accounting

Repairs never erase first-pass failures. Provider spending and human effort are accumulated across failed attempts and repairs. If no books are approved, report `no approved outputs` rather than a cost-per-approved-book figure.
